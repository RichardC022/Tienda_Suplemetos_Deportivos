# SysSupplementsGym

## 📑 Descripción
*SysSupplementsGym* es un sistema orientado a la gestión de suplementos y clientes en un entorno de gimnasio. El proyecto se desarrolla bajo una arquitectura **cliente-servidor**, con un backend implementado en **Java/Spring Boot**. La fase inicial se centra en la definición de la estructura del proyecto y la implementación del diagrama de clases, que constituye la base conceptual del sistema.

---

## 🛠️ Herramientas utilizadas
- **Lenguaje:** Java  
- **Framework:** Spring Boot  
- **Gestor de dependencias:** Maven  
- **IDE:** IntelliJ IDEA
